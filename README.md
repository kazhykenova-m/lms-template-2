# Forma LMS — шаблон платформы обучения

Отдельная установка для каждой компании. Существующая LMS и её данные не используются. В шаблоне нет онбординга, стандартов, коинов и привязок к Factum.

## Запуск на компьютере

Нужны PHP 8.1+ с PDO SQLite, mbstring и доступная для записи папка `storage`.

Из папки `lms-template`:

```sh
php -S 127.0.0.1:8080 router.php
```

Откройте http://127.0.0.1:8080. При первом открытии создайте администратора. Готовых аккаунтов и паролей в шаблоне нет.

## Первый запуск заказчиком

1. Создайте администратора.
2. В «Бренд платформы» задайте название, основной цвет и логотип.
3. В «Команда» добавьте сотрудников или загрузите CSV по `examples/users.csv`. Замените примерные данные и пароли своими. Кодировка UTF-8, разделитель — запятая. Поля с запятыми заключайте в двойные кавычки. Импорт атомарный: при ошибке строки не добавляются.
4. Создайте обучение через редактор или загрузите JSON по `examples/test.json`. `correct` — индекс ответа, начиная с нуля. Можно импортировать 2–8 вариантов, в визуальном редакторе — четыре.
5. Назначьте обучение выбранным сотрудникам; список можно выбрать по роли.
6. Передайте сотрудникам адрес платформы и их данные для входа безопасным способом.
7. После сдачи теста опубликуйте результат в разделе «Результаты».

У сотрудника одна попытка на обучение. Просмотр материала не запускает таймер. Таймер начинается после подтверждения старта; перезагрузка не продлевает его. Повторное назначение не сбрасывает попытку. При истечении времени несданный тест закрывается с результатом 0%. Черновик выбранных ответов сохраняется в браузере; отправка до окончания времени обязательна.

## Размещение на хостинге

Используйте PHP-хостинг с HTTPS, PHP 8.1+, PDO SQLite, mbstring. Загрузите содержимое папки, включая `.htaccess`. Apache должен разрешать `AllowOverride` и директиву `Require all denied`. Папка `storage` должна быть доступна PHP для записи, но закрыта для HTTP. **Проверьте, что запрос `/storage/platform.sqlite` возвращает 403/404.** Встроенный сервер PHP предназначен только для локального запуска с `router.php`.

Для Nginx добавьте в конфигурацию сайта, наряду с обычной настройкой PHP:

```nginx
location ^~ /storage/ { deny all; }
location ~ ^/(core|router)\.php$ { deny all; }
location ~ /\. { deny all; }
```

Если размещаете в подпапке, скорректируйте эти пути относительно неё. Удалите с публичного хостинга `tests`, `examples` и README; импортные файлы с паролями не должны оставаться в веб-каталоге. Завершите первичную установку до передачи адреса сотрудникам.

Данные находятся в `storage/platform.sqlite`. Для новой компании берите чистый архив, не копируйте рабочую базу другой компании. Для резервной копии используйте SQLite backup либо копируйте базу при остановленных запросах. Сохраните также файлы приложения. Логотип хранится в базе.

## Права и функции

- Администратор: оформление, создание обучений, добавление сотрудников, назначения, результаты и публикация.
- Сотрудник: назначенные материалы и тесты, собственные опубликованные результаты.
- Поле «роль» — должность/группа для назначения обучения; произвольный конструктор разрешений в этой версии не реализован.
- Тесты: один правильный вариант, автоматическая оценка, порог прохождения, ограничение времени.
- Правильные ответы остаются на сервере. Результат скрыт от сотрудника до публикации. Запись в API защищена CSRF-токеном.

## Проверка

`php -l core.php`, `php -l api.php`, `node --check assets/app.js`.

Интеграционный сценарий запускайте **только на новой одноразовой установке**, он создаёт тестовые данные:

```sh
python3 tests/smoke.py http://127.0.0.1:8080
```

Проверяет установку, бренд, создание пользователя и обучения, назначение, оценку, скрытие/публикацию результата, запрет второй попытки, права и откат ошибочного CSV-импорта через API.

## Границы первой версии

Это рабочая основа для отдельного развёртывания у клиента, а не многопользовательский SaaS для разных компаний в одной установке. Нет почтовых приглашений и восстановления пароля, SCORM, видеохранилища, открытых ответов с ручной проверкой, редактирования/архивации созданных обучений и конструктора прав. Для массового коммерческого запуска нужны проверка на целевом хостинге, визуальная приёмка в браузерах и нагрузочные проверки. Автоматические HTTP-проверки не заменяют их.
